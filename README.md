1. Download the entire zip and unzip
2. Install Xcode Command Line Tools (if not already installed) - `xcode-select --install`
3. Install Homebrew (if not already installed) - `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`
4. Install Node.js (if not already installed) - `brew install node`
5. Navigate to the directory in terminal and type `npm install`
6. Type `npx patch-package`
7. Type `node server.js`
8. Open `http://localhost:3000` in chrome
9. Enter your Braze email address and click "Authenticate" and wait for Snowflake to finish authentication
10. Enter the customer account name or Salesforce account ID and click Run query

More information on Confluence here: https://confluence.atl.braze.com/wiki/x/L4BYX
