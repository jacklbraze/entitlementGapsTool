Step 1: Download the entire zip and unzip
Step 2: Navigate to the directory in terminal and type "npm start"
Step 3: Open http://localhost:3000 in chrome
Step 4: Enter your Braze email address and customer name as it appears in Salesforce e.g. "King.com Limited"
Step 5: Click run query
Step 6: Authenticate with Okta if necessary and then close the tab that opens once you get confirmation that you authenticated
